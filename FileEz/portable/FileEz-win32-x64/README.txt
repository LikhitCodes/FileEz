🚀 FileEz - P2P File Sharing Desktop App
==========================================

Welcome to FileEz! This is a complete, portable desktop application 
for secure peer-to-peer file sharing.

🎯 QUICK START:
--------------
1. Double-click "FileEz.exe" to start the app
2. The app will automatically start the backend server
3. A modern dashboard will open in the app window
4. Find your IP address in the network section
5. Add friends as peers using their IP addresses
6. Start sharing files instantly!

📁 WHAT'S INCLUDED:
------------------
✅ FileEz.exe - Main desktop application
✅ Backend server - Runs automatically (p2p.exe) - STATICALLY LINKED!
✅ Simple HTML dashboard - Fast, lightweight interface
✅ All dependencies - No additional installs needed
✅ File storage system - Organized folders for sharing

🔧 FEATURES:
-----------
• 🔒 Secure local network sharing
• ⚡ Fast direct peer-to-peer transfer
• 📊 Real-time transfer tracking and history
• 🎨 Clean, easy-to-use interface
• 📱 Responsive web interface
• 🔄 Auto-resume interrupted transfers

🌐 NETWORK REQUIREMENTS:
-----------------------
• Same WiFi network for all users
• Windows Firewall may ask for permission (click "Allow")
• Default ports: 8080 (web interface), 8081 (file sharing)

📦 SHARING WITH FRIENDS:
-----------------------
This entire folder is portable! To share:
1. Zip the complete "FileEz-win32-x64" folder
2. Send to friends
3. They extract and run FileEz.exe
4. No installation or setup required!

🔧 FIXED ISSUES:
---------------
✅ DLL dependency issues resolved (statically linked backend)
✅ Download functionality fixed (correct API endpoints)
✅ File browsing improved (better error handling)
✅ Works on any Windows system without additional runtime libraries

🐛 TROUBLESHOOTING:
------------------
• If app won't start: Check Windows Firewall settings
• If can't see friends: Verify IP addresses and same network
• If downloads fail: Ensure friend's server is running and files are shared
• For help: Check the built-in help menu in FileEz
