================================================ 
  P2P FILE SHARING - QUICK START GUIDE 
================================================ 
 
SUPER EASY SETUP (2 minutes): 
 
1. EXTRACT THIS FOLDER 
   - Put it on your Desktop or Documents 
 
2. FIND YOUR IP 
   - Double-click "FIND_MY_IP.bat" 
   - Write down your IP (like 192.168.1.100) 
   - Send this IP to your friend 
 
3. START THE SYSTEM 
   - Double-click "START_P2P_SYSTEM.bat" 
   - A web page will open automatically 
   - Keep the black window open! 
 
4. ADD YOUR FRIEND 
   - In the web page, find "Peer Management" 
   - Enter your friend's IP and port 8081 
   - Click "Add Peer" 
 
5. START SHARING 
   - Click "Start Server" (green button) 
   - Upload files using the file picker 
   - Download files by clicking "Browse Peer Files" 
 
THAT'S IT! You're now sharing files! 
 
TROUBLESHOOTING: 
- Web page won't load? Try: http://127.0.0.1:8080 
- Can't see friend's files? Both click "Start Server" 
- Still problems? Turn off Windows Firewall temporarily 
 
FILES LOCATIONS: 
- Share files: Put them in data\shared\ folder 
- Downloaded files: Find them in data\downloads\ folder
