================================================ 
  P2P FILE SHARING - PORTABLE VERSION 
================================================ 
 
QUICK START: 
 
1. Double-click START_P2P.bat for interactive mode 
   OR 
2. Use SHARE_FILE.bat to share files 
3. Use DOWNLOAD_FILE.bat to download files 
 
IMPORTANT: 
- Both computers must be on the same network 
- Edit peers.txt to add other computer's IP:PORT 
- Put files to share in: data\shared\ 
- Downloaded files appear in: data\downloads\ 
 
See USER_GUIDE.md for detailed instructions 
================================================
